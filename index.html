Data rules

Aggressor side: Binance aggTrade m=true means buyer is maker, therefore taker sell; m=false means taker buy.

Hot flow: the browser seeds only the latest public aggregate trades, then accumulates WebSocket data while the tab stays open. A selected 4h/8h/12h window never implies that much history unless the coverage line actually shows it.

Weekly VP: GitHub Actions downloads official Binance Vision daily USD-M aggTrades archives, verifies SHA-256 checksums, and aggregates actual reported trade prices.

No order placement, private account API, wallet access, liquidation reconstruction, or order-book heatmap.

Research prototype. Actual coverage is shown explicitly; missing history is not synthesized.
