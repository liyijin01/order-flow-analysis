Data rules and local preview

Aggressor side: Binance aggTrade m=true means buyer is maker, therefore taker sell; m=false means taker buy.

Sequence integrity: aggTrade IDs are monitored. Missing ID ranges are repaired through public REST fromId pagination at no more than 60 requests/minute. If repair cannot complete, the coverage line shows the gap and the CVD line breaks there.

Memory: the default in-browser cap is 1,000,000 aggregate trades and can be changed with ?maxTrades=2000000. If the cap truncates data, coverage says so explicitly.

Local file mode: this page uses classic scripts, so double-clicking index.html no longer fails because of ES-module CORS. Browser security may still block loading local archive JSON; use python3 -m http.server 8000 for full local preview.

Weekly VP: GitHub Actions builds per-symbol profiles from checksum-verified Binance Vision daily aggTrades archives. Missing UTC days are never interpolated and are shown as incomplete.

No order placement, private account API, wallet access, or API keys.
