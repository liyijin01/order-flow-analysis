# docs 目录说明

这个目录记录项目的所有变更、关键决定和后续计划。新开对话（不论是 Claude 还是 GPT）时，先读这里，就能接上之前的进度，不依赖旧对话。

| 文件 | 内容 |
|---|---|
| `ROADMAP.md` | 已完成和待完成的任务清单，**先看这个** |
| `CHANGELOG.md` | 每一轮（Phase / C / D 编号）做了什么，对应的提交和 PR |
| `DECISIONS.md` | 已经定下来、不要随意改的定义和规则，以及验证依据 |
| `HANDOFF.md` | 新开 GPT 对话时发的第一段话 |
| `specs/` | 每一轮的任务文档原文（`D12.md` 等） |

## 每个 PR 都要做的三件事

1. 把本轮任务文档原样保存为 `docs/specs/{编号}.md`。
2. 在 `CHANGELOG.md` 末尾追加一行：编号、日期、提交、PR、做了什么、关键决定。
3. 更新 `ROADMAP.md` 的状态；如果本轮改变了某个定义或规则，同步更新 `DECISIONS.md`。
