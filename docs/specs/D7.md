## 1. 问题（均已复现）

复现环境：headless Chromium 加载 D6 的 `flow.html`（main `e8fd0b4` 中这部分代码与我测试的版本相同，`web/flow/main.js` 第 76 行仍是逐个 `setHeight()`），实时模式，K 线为模拟行情，深度数据使用与 `d6_build_flow_snapshot.py` 输出格式相同的合成数据。

| ID | 现象 | 证据 |
|---|---|---|
| F1 | CVD 和深度窗格被压扁，几乎看不到 | 配置比例是 45 / 11 / 11 / 12 / 10.5 / 10.5（%），1660px 宽时实测 6 个 pane 高度是 722 / 30 / 30 / 30 / 30 / 103px，也就是 76.4 / 3.2 / 3.2 / 3.2 / 3.2 / 10.9%。原因：`web/flow/main.js` 第 74~76 行对每个 pane 依次 `setHeight()`。LWC 5 的 `setHeight` 实际是移动这个 pane 和相邻 pane 之间的分隔线，逐个调用会互相覆盖。我在页面里改用 `pane.setStretchFactor(ratio × 1000)` 后实测为 45 / 11 / 11 / 12 / 10.5 / 10.6%，桌面和 390px 手机都正确 |
| F2 | CVD 和深度窗格的价格轴显示 `10000000.00`、`-100000000.00` 这样的原始数字 | 5 个副图 series 的 `priceFormat` 都是 `{type:'price', precision:2, minMove:0.01}`，没有用 K / M / B 格式。手机上这些长数字还会和 pane 标签重叠。深度截止竖线的文字 `depth archive through …` 在 3 个深度 pane 里各竖着画了一遍，压在柱子上 |
| F3 | pane 标签和下方表格对同一个 CVD 给出不同的数值和起点 | 同一时刻，合约 CVD 的 pane 标签是 `+294.3M · from 2026/09/26 09:30`，表格是 `+205.5M`、起点 `2026/09/26 11:30`，相差 8 根 bar。手机上也一样（标签 `+1.69M`，表格 `−43.4M`）。原因：首次渲染后，settle 步骤按实际宽度重建了 model 并更新了表格，pane 标签没有随之重画，停留在第一次的 model 上 |
| F4 | smoke 没有覆盖 F1 到 F3 | `scripts/d6_smoke.cjs` 检查了 pane 数量、时间戳、autoscale 和标签是否存在，没有检查 pane 高度比例、副图价格格式、标签与表格是否一致 |

## 2. 修复规格

### F1 pane 高度（`web/flow/main.js`）

- 把第 74~76 行逐个 `setHeight()` 的写法改为对每个 pane 调用 `setStretchFactor(Math.round(ratio × 1000))`，ratio 取自 `config/flow-rules.json` 的 `panes`。
- 创建 pane 后、每次切换币种 / 周期后、ResizeObserver 回调后都执行一次。

### F2 副图数值格式与截止标注（`web/flow/main.js`）

- 两个 CVD series 和所有深度 series（bid 线、ask 线、3 个差值柱）的 `priceFormat` 改为 `{type:'custom', minMove:1, formatter: v => F.formatSigned(v)}`，和 pane 标签用同一个 K / M / B 格式函数。
- 深度截止竖线的文字只在**第一个深度 pane** 顶部**横向**显示一次，内容为 `depth archive through YYYY-MM-DD 23:59 UTC`；另外两个深度 pane 只画竖线，不写字。

### F3 标签与表格同源（`web/flow/main.js`）

- 把“更新 pane 标签”和“渲染表格”放进同一个函数，接收同一个最终 model。首次加载、settle 重建 model、ResizeObserver 重建、切换币种 / 周期 / 锚点、定时刷新之后都调用这个函数，禁止只更新其中一边。

### F4 smoke 补断言（`scripts/d6_smoke.cjs`）

- 桌面 1600×1200 和手机 390×844 下，6 个 pane 的实际高度占比与 `panes` 配置的差都 ≤ 2 个百分点。
- 5 个副图 series 的 `priceFormat.type === 'custom'`。
- 每个 pane 标签里的 CVD 数值和起点时间，与表格对应行完全一致；手机宽度下同样成立。
- 深度截止文字在页面上只出现一次。
- 现有断言全部保留。
