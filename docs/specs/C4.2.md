## 0. 为什么要做这一步

图表库和渲染器本身没有问题。我用**同一个页面、同一个图表库、同一套 primitive**，只改了"画哪些东西、怎么组合"，出来的图就已经接近参考图的结构了（对比图见 `compare-p1.png`、`compare-p3.png`）。

差距集中在三点：

1. **价位的定义**：P1 的 VAH / VAL 应该是该周期结束时 VWAP 的 ±1σ，见 C4.1 第 2 节。
2. **构图**：参考图只画少数几条关键线，还会把上个周期的 VWAP 带"平铺"延续到下一个周期；现在的页面则自动加了大量事件文字和标记。
3. **TPO 的画法**：参考图的 TPO 是按周期排列的方块剖面；现在画的是细长的横条直方图，而且只画了最后 3 个周期。

## 1. P1 季度价值区：构图规范

**图层从下到上：**

1. **每个季度独立的锚定 VWAP 带**，季度切换时重新开始计算：
   - 绿色 VWAP 线
   - ±1σ 之间灰色半透明填充，上下沿是灰色细线
   - 从数据起点开始，每个季度一段
2. **上一季度的平铺投影**：上季结束时的 VWAP、+1σ、−1σ，在**下一个季度**里画成水平的：
   - 灰色半透明矩形：+1σ 到 −1σ
   - 深绿色实线：VWAP，标签 `PQ VWAP`
   - 每个季度都这样处理，最后一段延伸到最右侧
3. **关键价位虚线**：白色虚线，横跨整张图，右端写文字，价格轴上是白底标签。默认最多 6 条，按离现价远近选取，候选如下：
   - `{Qn} VAH` / `{Qn} VAL`：今年已结束各季度的 ±1σ 期末值
   - `PQ VAH` / `PQ VAL`：和上季的 `{Qn}` 是同一组数，两个标签合并显示，例如 `Q2 VAH · PQ VAH`
   - `PY Q1` 到 `PY Q4` 的 VAH / VAL
   - `PY {月} VAH / VAL`：去年各月，用**月度**锚定 VWAP 的 ±1σ 期末值；这类线用青色实线
4. **价格轴标签**：本季 VWAP、±1σ 当前值，用绿色和灰色标签，只显示在价格轴上，图里不画线。
5. **左上信息行第 2 行**：`Anchored VWAP (hlc3, Quarter, ±1σ)` 后面跟 6 个数：本季 VWAP、+1σ、−1σ、上季 VWAP、上季 +1σ、上季 −1σ。

**默认关闭**：触及、穿越等事件标记，以及它们的文字。在控制栏加一个"事件标记"开关，默认关闭。

**历史长度**：要算到 `PY Q4`、`PY Nov` 这类价位，1h K 线至少要覆盖"去年 1 月 1 日到现在"，约 11,000 根，需要分页约 8 次请求。加载时状态栏显示进度。

## 2. P3 周度 TPO（P2 月度同理）：构图规范

1. **可见范围内的每一个周期**都画 TPO 剖面，包括正在形成的这一个；正在形成的剖面，POC 标签写 `dPOC`。
2. **方块画法**：
   - 每个 30 分钟时段在它覆盖到的每个价格档里记一个方块，从周期起点向右依次排列
   - 方块高度等于档高；宽度等于 `min(档高像素, 周期宽度 × 0.75 ÷ 最长一行的方块数)`
   - 价值区内的方块用浅色（约 `rgba(236,239,244,.85)`），价值区外用灰色（约 `rgba(140,146,158,.55)`），POC 那一行用红色
3. **剖面左侧**写 `VAH ▸`、`POC ▸`、`VAL ▸`：VAH、VAL 用青色，POC 用红色。
4. **未回补价位**：已结束周期的 POC（暗红色实线）、VAH 和 VAL（青色点线）从周期结束时刻向右延伸，在第一根触及它的 K 线处截止；从未被触及的一直画到最右侧。
5. **档高**（更正 C4.1 §4 B10 里"默认 100 个 tick"的写法）：
   - 默认**自动**取值：取可见周期价格范围的中位数，除以 45，再向上取到"好看的整数"（10、20、25、50、100、150、200、250、500、1000 等）。
   - `config/symbols.json` 里的 `tpoRow` 可以覆盖自动值。
   - 更正原因：实测 BTC 按 10 USDT 一档，每周有 600 多档，方块小到看不见；自动取值得到 150 USDT 一档、约 45 行，和参考图的密度一致。
6. **放弃 `single prints` 的横条画法**：单印在方块剖面里本来就能看出来（只有一格宽的那几行）。如果需要额外突出，只在剖面内部把这些行的方块描边，不要另外画横贯整周的框。

## 3. 参考实现

下面两段代码就是生成对比图时用的，直接在 `chart.html` 页面里运行，依赖页面上已有的 `OrderFlowIndicators` 和 `__orderFlowChartDebug`。可以作为改写 `annotate.js` 和新增 TPO 方块 primitive 的参照。

### 3.1 P1：按季度分段的 VWAP 带、上季投影、关键价位

```js
const D = window.__orderFlowChartDebug, I = window.OrderFlowIndicators, bars = D.state.data;
const quarters = []; let q = I.utcQuarterStart(bars[0].time);
while (q <= bars.at(-1).time) { const d = new Date(q * 1000); const next = Date.UTC(d.getUTCFullYear(), d.getUTCMonth() + 3, 1) / 1000; quarters.push([q, next]); q = next; }
const items = [], finals = {};
for (const [s, e] of quarters) {
  const qb = bars.filter(b => b.time >= s && b.time < e); if (!qb.length) continue;
  const v = I.anchoredVwap(qb, s, 1);
  items.push({ id: 'vwap-' + s, type: 'band', label: 'Q VWAP', points: v.map(p => [p.time, p.vwap, p.upper, p.lower]), color: '#5cb85c', fill: 'rgba(190,196,208,0.10)', source: 'exact' });
  const last = v.at(-1); finals[s] = { vwap: last.vwap, upper: last.upper, lower: last.lower, full: qb[0].time === s, end: e };
}
const qs = Object.keys(finals).map(Number).sort((a, b) => a - b);
for (let i = 1; i < qs.length; i++) {
  const p = finals[qs[i - 1]]; if (!p.full) continue;          // 只有完整季度才能投影
  const to = i === qs.length - 1 ? null : finals[qs[i]].end;
  items.push({ id: 'proj-' + qs[i], type: 'zone', top: p.upper, bottom: p.lower, from: qs[i], to, label: ' ', border: 'rgba(0,0,0,0)', fill: 'rgba(190,196,208,0.07)', source: 'exact' });
  items.push({ id: 'pvwap-' + qs[i], type: 'level', price: p.vwap, label: 'PQ VWAP', from: qs[i], to, style: 'solid', color: '#2e7d32', axisLabel: i === qs.length - 1, source: 'exact' });
}
// 关键价位：横跨整张图的白色虚线（from = 第一根 K 线）
```

### 3.2 P3：TPO 方块剖面和未回补价位

```js
// 分组：I.periodKey(t,'week')；档高：见第 2 节第 5 条
// 每个价格档的方块数 = 覆盖该档的 30m K 线根数；价值区用 I.valueArea(rows,row,0.7)
// 绘制（primitive 的 draw，使用 media 坐标）：
for (const p of profiles) {
  const x0 = x(p.from), x1 = x(p.end - 1800);
  let maxN = 1; for (const r of p.rows) if (r[1] > maxN) maxN = r[1]; // CI 禁止 Math.max(...arr) 写法
  const cellH = Math.abs(y(p.rows[0][0]) - y(p.rows[0][0] + row));
  const cellW = Math.max(1, Math.min(cellH, (x1 - x0) * 0.75 / maxN));
  for (const [price, n] of p.rows) {
    const inVa = price >= p.val && price + row <= p.vah, isPoc = Math.abs(price + row / 2 - p.poc) < row / 2;
    ctx.fillStyle = isPoc ? 'rgba(229,57,53,.9)' : inVa ? 'rgba(236,239,244,.85)' : 'rgba(140,146,158,.55)';
    for (let j = 0; j < n; j++) ctx.fillRect(x0 + j * cellW + .5, y(price + row) + .5, Math.max(1, cellW - 1), Math.max(1, cellH - 1));
  }
}
// 未回补：已结束周期的 POC/VAH/VAL，从 p.end 起找第一根 low<=价格<=high 的 K 线作为终点
```
