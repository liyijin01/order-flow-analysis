## 1. 背景

KBeast 2026-10-05 发了一张 TradingView 图：`USDT.D+USDC.D+DAI.D`（CRYPTOCAP，日线，2022-06 到现在）。他的读法：

- 9.064% 是 2024-08 和 2025-04 两次恐慌高点（图上标 `2024 8.4`、`2025 4.7`）连成的阻力，现在回踩当支撑；
- 跌破它，资金从稳定币流回币市，“跌了大饼就能去 90,000”；
- 图上其他水平位：12.829%、10.490%（2026 年的区间上下沿）、9.642% / 8.372%（2025-11~12 的小区间）、5.114%（2024 年低点），虚线 13.719%、11.886%、2.463%。

TradingView 的定义：`X.D = X 的市值 / TOTAL × 100%`，`TOTAL` 是**前 125 个币**的总市值。TradingView 的数据不能拿来公开展示，所以我们用 CoinGecko 的免费数据自己算。免费数据只有最近 365 天，2024、2025 那两个高点算不出来，所以他图上的水平位按**手动关键位**写进配置。

## 2. 实现规格

### D20-1 数据：`scripts/d20_build_ssd.py`

数据源：CoinGecko Demo API（`https://api.coingecko.com/api/v3`，请求头 `x-cg-demo-api-key`，限速约 30 次 / 分钟，遇到 429 退避重试）。

1. **分子**：`tether`、`usd-coin`、`dai` 三个币的市值。
2. **分母（前 125）**：
   - 用 `/coins/markets?vs_currency=usd&order=market_cap_desc&per_page=250` 取当前排名；
   - **去掉包装币和流动性质押币**，避免重复计算（例如 WBTC、stETH）：用 `/coins/markets?category=wrapped-tokens` 和 `category=liquid-staking-tokens` 取这两类的 id 作为排除名单；
   - 排除后取市值前 125 个，作为分母成分。成分名单每月 1 日更新一次，存进缓存。
3. **回填（缓存为空时只跑一次）**：对分母成分和三个稳定币，各调一次 `/coins/{id}/market_chart?vs_currency=usd&days=365&interval=daily`，只取 00:00 UTC 的点，按日期求和。某个币在某天没有数据就按 0 计，并在缓存里记下当天缺了几个币。
4. **每天更新**：data job 运行时用 `/coins/markets` 取当前值，按同样的成分和排除规则算出当天的点，记为“当天 00:00 UTC”。如果当天的点已经存在就不覆盖。GitHub 定时任务可能延迟几个小时，所以要记下实际取数时间 `fetchedAt`。
5. **缓存和输出**：缓存放 data 分支 `macro/ssd.json`，输出 `analysis/macro/ssd.json`：`{schema, generatedAt, source:"CoinGecko Demo API", denominator:"top-125 excl. wrapped & liquid staking", constituentsUpdatedAt, calibration:{...}, points:[{date, usdt, usdc, dai, total, raw, fetchedAt, missingCoins}]}`。`raw = (usdt + usdc + dai) / total × 100`。
6. **没有 secret 或 API 出错时**：打印 `::warning::`，保留缓存里已有的数据照常输出，**不要让 data job 失败**。
7. **校准**：我们的分母和 TradingView 不完全一样，所以用一个点校准：他图上 2026-10-05 那根日线的“前一日收盘”是 **9.118%**（截图显示收盘 9.068%、涨跌 −0.050），对应我们 `2026-10-05` 那个 00:00 UTC 的点。`ratio = raw(2026-10-05) / 9.118`，图上画 `raw / ratio`（TradingView 口径）。`ratio` 写进 `calibration`，`|ratio − 1| > 5%` 时打 `::warning::`。这个参考值放在配置里（`ssd.calibration: {date: "2026-10-05", tvValue: 9.118}`），以后可以换。

### D20-3 模板 `ssd`

`templates` 新增 `ssd`，按钮组加 `稳定币占比`（放在 `综合` 前面），URL `tpl=ssd`。

| 项目 | 规格 |
|---|---|
| 数据 | 只读 `analysis/macro/ssd.json`，**不向 Binance 发请求**（`needs()` 为空）。在 D19b 的架构里加一个通用的“非 K 线数据源”入口，模板声明 `dataSource: "macro/ssd"` 即可，不要在 `main.js` 里写模板 id |
| 币种按钮 | 这个模板与币种无关，币种按钮隐藏（模板配置 `symbolIndependent: true`） |
| 画法 | 白色 1.5px 折线（TradingView 口径的值），K 线 series 隐藏；价格轴格式 `9.068%`（3 位小数） |
| 默认范围 | 全部数据，右侧留白 30% |
| 水印 | `USDT.D+USDC.D+DAI.D, 1天` |
| 图内信息第 2 行 | `Stablecoin dominance (top-125, TV-calibrated)  9.068%  raw 8.951%  ·  Δ1d −0.050pp  ·  Above 10.490% (+1.42pp)  ·  Below 9.064% (−0.00pp)` |
| 页脚 | `Data: CoinGecko`（CoinGecko 免费 API 要求注明来源） |
| 可选叠加 | URL 加 `overlay=btc` 时，在左侧价格轴叠加 BTCUSDT 日线收盘价（灰色 1px，`invertScale: true`，用来看两者反向）。默认不显示，PNG 也不显示。这一项需要 1 次 Binance 请求 |
| 关闭 | 其他所有图层、成交量副图、图例、表格、收盘倒计时 |
| 过期提示 | D18-5 的提示也检查 `analysis/macro/ssd.json` 的 `generatedAt`；`status.json` 加 `ssdGeneratedAt` 和 `ssdLastDate` |
