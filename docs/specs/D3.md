## 1. 问题（已复现）

复现环境：headless Chromium 加载 `analysis.html`，LWC 5.2.1，K 线为模拟行情。

| ID | 现象 | 复现步骤与结果 | 根因 |
|---|---|---|---|
| D3-1 | 从 BTC 切到 ETH / SOL 后图表一片空白，价格轴仍停在 BTC 的 6.7 万~11 万 | BTC 4h 加载后，在右侧价格轴上按住鼠标上下拖动 80px，`candles.priceScale().options().autoScale` 变为 `false`。之后点 ETH：价格轴仍是 67,200 ~ 109,679，ETH 的 K 线在 1,867 ~ 3,304，完全不在视野内。切 SOL 同样如此。没有拖过价格轴时切换正常 | LWC 的规则是：用户拖动价格轴后，该价格轴 `autoScale` 自动关闭，而且之后一直保持关闭。代码在切换币种 / 周期时从未把它重新打开。切换周期（4h → 1D）也会遇到同一问题；成交量副图的价格轴同理 |
| D3-2 | 切到 ETH / SOL 后，价格轴刻度、最新价标签和十字光标的价格精度仍按 BTC 显示 | 切到 ETH 后 `priceFormat` 仍为 `{precision:1, minMove:0.1}`，最新价标签显示 `2733.0`（应为 `2,732.97`）；SOL 同样显示 1 位小数（应为 3 位，tick 0.001） | `createChart()` 只在页面初始化时按当时的币种设置一次 `priceFormat`，切换币种时没有更新 |

## 2. 修复规格

### D3-1 切换视图时恢复自动缩放（`web/analysis/main.js`）

在 `applySeries(model)` 里，`sameView === false`（首次加载、切换币种、切换周期）时，**在 `setData` 之前**执行：

```js
state.candles.priceScale().applyOptions({autoScale:true});
state.volume.priceScale().applyOptions({autoScale:true});
```

- `sameView === true`（60 秒定时刷新、30 分钟全量重载）时**不要**碰 `autoScale`：用户手动调整过的价格范围和时间范围都保持不变，与 D2-6 的规则一致。
- 我用上面两行在本地验证过：拖动价格轴后切到 ETH，价格轴变为 1,867 ~ 3,304，K 线完整可见；再切 SOL 同样正常。

### D3-2 切换币种时更新价格精度（`web/analysis/main.js`）

同样在 `sameView === false` 时，按当前币种的 `tickSize` 更新：

```js
const tick=Number(symbolMeta().tickSize)||.01;
const fmt={type:'price',precision:pricePrecision(),minMove:tick};
state.candles.applyOptions({priceFormat:fmt});
state.vwap.applyOptions({priceFormat:fmt});
```

验证结果：ETH 为 `precision 2 / minMove 0.01`，SOL 为 `precision 3 / minMove 0.001`。

### D3-3 “重置视图”按钮（`analysis.html`，`web/analysis/main.js`）

- 在“下载 PNG”按钮左边加 `<button id="resetViewBtn" title="也可以双击价格轴恢复自动缩放">重置视图</button>`。
- 点击后：两个价格轴 `autoScale:true`，时间轴恢复 `defaultVisibleRange(当前K线数)`，即最近 `visibleBars` 根 K 线加右侧留白。
- 快照模式下 `.controls` 本来就隐藏，不用额外处理。
- 页脚左侧的 `Display time: JST · calculations use UTC boundaries` 后面补一句 `· 双击价格轴或点“重置视图”恢复自动缩放`。

## 3. 回归测试（`scripts/d1_smoke.cjs`，在 CI 的 analysis-smoke 里跑）

用**真实鼠标拖动**价格轴来关闭 autoScale：价格轴 x = `#analysisChart` 右边缘 − 30px，按住后纵向移动 80px 再松开。每一步先断言 `autoScale === false`，证明拖动确实生效。

定义“K 线在视野内”：`candles.coordinateToPrice(0) >= model.viewMax` 且 `candles.coordinateToPrice(主图pane高度) <= model.viewMin`。

1. **手动范围在同视图刷新时保留**：BTC 4h 拖动价格轴后调用 `__analysisDebug.refresh()`，`autoScale` 仍为 `false`，价格轴上下边界变化 ≤ 0.5%。
2. **切换币种**：接着点 ETH。两个价格轴 `autoScale === true`，K 线在视野内，`priceFormat` 为 `precision 2 / minMove 0.01`。再点 SOL：K 线在视野内，`precision 3 / minMove 0.001`。
3. **切换周期**：SOL 4h 拖动价格轴后点 1D，K 线在视野内，`autoScale === true`。
4. **成交量副图**：拖动副图的价格轴后切换币种，`state.volume.priceScale().options().autoScale === true`。
5. **重置按钮**：拖动价格轴并平移时间轴后点“重置视图”，`autoScale === true`，时间轴逻辑跨度 = `visibleBars + rightOffset`（允许 ±2）。
6. D2 已有的断言全部保留。
