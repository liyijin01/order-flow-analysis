## 2. 实现规格

### D12b-1 修复每日构建

- 按日志确认的原因修复。如果就是高度上限：综合模板 PNG 的高度上限改为按表格行数计算（表头 + 图 + 表格行数 × 行高 + 页脚，再加 20px 余量），不再写死 1300px；季度模板保持 ≤ 900px 不变。
- 同时给综合模板表格加一个上限：最多 16 行，超出部分合并成一行“另有 N 条”，和现有的“关键价位 · 另有 N 条不在当前视图”同样处理。
- 加一个回归测试，覆盖“新季度第 1 天”的情况：用 `2026-10-01T23:59:59Z` 截止的数据（模拟数据即可）生成 15 张 PNG 全部通过。

### D12b-2 线的最小间距按像素保证

- `selectKeyLevels` 的最小间距改为两者取大：`minGapPct`（现有 2%）和 `minGapPx`（新增，`config/analysis-rules.json` 的 `keyLevels.minGapPx: 18`）。像素换算用默认视图的价格范围（含 autoscale 留白）和主图高度：`每像素价格 = 价格范围 / 主图高度`。
- `PQ VWAP`、`PQ VAH`、`PQ VAL` 都放进 `reservedPrices`，先占位；关键价位和它们的距离也要满足上面的最小间距。
- 18px 的含义：标签 12px 写在线的上方，相邻两条线至少隔 18px，标签就不会压到别的线。
- “综合”模板用同一个函数，所以也会少画几条挨得太近的线，这是预期的。D11 的断言如果因此需要调整，写进回复。

### D12b-3 价格轴标签和收盘倒计时

1. 季度模板的虚线（关键价位、`PQ VAH`、`PQ VAL`）恢复价格轴标签：**灰底 `#3a4152`、白字 `#eceff4`**；`PQ VWAP` 用它的深绿色底。重叠时沿用现有 `axisLabelSelection` 规则隐藏优先级低的。
2. 收盘倒计时移到价格轴：在最新价标签**正下方**再画一个同样宽度、同样底色的轴标签，只写剩余时间（例如 `35:08`，超过 1 小时写 `02:35:07`）。用现有 primitive 的价格轴标签实现，每秒更新。删除图内那段 `最新价 · 倒计时` 文字。
3. 倒计时标签的位置也放进 `axisLabelSelection` 的 `reserved`，其他轴标签不能压住它。
4. 快照模式（PNG）仍然不显示倒计时（D9 的断言不变）。

### 测试（写进 `scripts/d1_smoke.cjs` 或 `web/tests/`）

- 季度模板 4h：画出的所有水平线（关键价位 + PQ 三条）两两之间的像素距离 ≥ 18px。
- `selectKeyLevels` 单元测试：给定价格范围和主图高度，验证 `minGapPx` 生效；验证 `PQ VWAP` 在 `reservedPrices` 里时，离它 1% 的关键价位被跳过。
- 实时模式：倒计时轴标签存在，位置在最新价标签下方，和任何其他轴标签的距离 ≥ 14px；图内不再有倒计时文字。
- 季度模板的关键价位在价格轴上有标签（未被碰撞隐藏的那些）。
