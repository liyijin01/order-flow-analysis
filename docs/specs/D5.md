## 2. 修复规格

### D5-1 尺寸变化后按真实宽度重算默认视窗（`web/analysis/main.js`）

- ResizeObserver 回调里只做 `chart.resize()`、调整副图高度，并记录“调整前是否是默认视图”（`wasDefault`）。
- 重算放到异步执行并做防抖：最后一次尺寸变化之后，等 2 个 `requestAnimationFrame`，再调用 `settleDefaultWindow(state.bundle)`。这个函数已经会逐帧等到 `timeScale().width()` 稳定，然后按新宽度套用默认视窗；需要时重建 model，保证 `visibleBars` 和“图外”判断同步。
- `wasDefault === false`（用户手动调过视图）时，只 resize，不改视窗。
- 同一时刻只允许一个 settle 在跑（与 D4 的 `inFlight` 思路一致），新的尺寸变化到来时取消旧的。

### D5-2 最新价标签优先，并按真实标签高度避让（`web/analysis/engine.js`，`web/analysis/primitive.js`，`config/analysis-rules.json`）

- `axisLabels.minGapPx` 从 14 改为 18（与 12px 字体的实际标签高度一致）。
- `axisLabelSelection` 新增可选参数 `reserved`（像素 y 数组）。任何自定义标签距离任一 reserved y 小于 `minGap` 时 `visible=false`，不移动它的位置（价格轴标签必须对准真实价格，这一点保持不变）。
- `primitive.axisLayout()` 把 `series.priceToCoordinate(currentPrice)` 作为 reserved 传入。
- 被隐藏的轴标签对应的区域仍然在图内画框和文字标签，表格也照常列出，不丢信息。
- 单测：reserved = 100 时，y = 90 和 y = 115 的标签隐藏，y = 120 的标签保留，保留下来的标签 y 不变。

### D5-3 删除旧预览 workflow 并清理已合并分支

- 删除 `.github/workflows/c4-1-online-review.yml`。`scripts/c4_1_real_screenshots.cjs` 等脚本保留。
- 删除远程分支：`c0-chart-skeleton c1-chart-basics c2-1-c3-c4 c2-annotation-primitives c2-annotation-renderer c4-1-annotation-fixes d1-analysis-board d2-board-fixes d3-switch-autoscale d4-board-robustness phase-0-refactor-tests phase-1-2-hardening`。**只删对应 PR 已 merged 或 closed 的分支**，逐个核对；`main` 和 `data` 绝对不能删。PR 页面仍然保留完整 diff，需要时可以从 PR 页面恢复分支。
- 在仓库 Settings → General 打开 “Automatically delete head branches”。以后合并 PR 后自动删分支，D5 自己的分支也会在合并后自动删除。如果没有权限修改设置，在回复里说明。
- 回复里列出实际删除的分支和对应 PR 编号。

### D5-4 图例与时间显示统一（`analysis.html`，`web/analysis/export.js`，`web/analysis/main.js`）

- 页面图例和 PNG 导出图例改为同一套 8 项，颜色取自 `config/analysis-rules.json`：`PQ 上季价值区`（pqBorder）、`PM 上月价值区`（pmBorder）、`PW 上周价值区`（pwBorder）、`供应区`、`需求区`、`本季 VWAP`（vwap，实线）、`PQ VWAP`（pqVwap，实线）、`未回补 POC`（nPoc，虚线）。`export.js` 不要再硬编码颜色，改为由 `main.js` 传入同一份图例配置。
- 快照模式页脚改为 `数据截至 {同标题行的 JST 时间} JST`，和标题行一致，不再单独显示 UTC 日期。实时模式页脚不变。
- 宽度 ≤ 600px 时隐藏表格的“数据来源”列，并把单元格左右 padding 从 9px 减到 6px，让“计算周期”列在 390px 宽度下完整显示。

### D5-5 测试不再输出 `::warning::`（`pipeline/build.py`，`pipeline/tests/test_build.py`）

- `build.py` 的两处 `print("::warning::...")` 改为通过一个模块级函数 `warn(msg)` 输出；`build_all` 增加可选参数 `warn=None`，默认打印 `::warning::`（线上 data job 行为不变）。
- 测试调用 `build_all` 时传入收集函数，并断言收集到了预期警告。这样测试仍然覆盖警告逻辑，但不再污染 Actions 注释。

## 3. 回归测试（`scripts/d1_smoke.cjs`，`web/tests/*.test.mjs`）

1. **旋转**：视口 390×844（`isMobile`、`deviceScaleFactor 3`），ETH 4h 加载完成后：
   - `setViewportSize(844, 390)`，等待 1.5 秒：`barSpacing` 在 5~9 之间，`model.visibleBars === min(180, floor(paneWidth / (5 × (1 + 30/180))))`；
   - 再 `setViewportSize(390, 844)`，等待 1.5 秒：`barSpacing >= 5`，`model.visibleBars <= 50`；
   - 先手动平移时间轴再旋转：逻辑范围保持不变（不被重置）。
2. **最新价避让**：9 个（币种 × 周期）桌面视图中，所有 `visible` 的自定义轴标签满足 `|y − y(最新价)| >= 18`，并且任意两个可见标签之间的距离 >= 18。
3. **图例**：页面图例和导出 PNG 前的图例配置都包含 PQ / PM / PW / 供应区 / 需求区 / 本季 VWAP / PQ VWAP / 未回补 POC，颜色与 rules 一致。
4. **手机表格**：390px 宽度下“数据来源”列不可见，`document.documentElement.scrollWidth === clientWidth`。
5. D2~D4 已有的断言全部保留。
