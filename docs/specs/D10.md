## 1. 背景

他的季度价值区图上，除了季度 VWAP 灰带，还有几条横跨整张图的白色虚线，右端写着 `Q1 VAH`、`Q2 VAH`、`PQ VAL`、`PY Q4 VAL`、`PY Nov VAL` 这类标签。D9 之后我们的图已经有了灰带，只差这些价位。
算这些价位需要一年以上的历史数据，浏览器实时拉取太重，所以改成 CI 每天预计算成一个小文件，页面只读这个文件。

两种价位的定义都已经用他图上的数字验证过，**不要改**：

| 价位 | 定义 | 验证 |
|---|---|---|
| 季度：`Q1 VAH / VAL`、`PY Q1~Q4 VAH / VAL` | 该季度 1h K 线、季度起点锚定的 VWAP（hlc3，成交量加权），季度结束时的 VWAP ±1σ（成交量加权总体标准差） | `scripts/c4_1_golden.py`：ETH 2026Q2 = (2008.09, 2295.37, 1720.81) 等 6 组 |
| 去年月份：`PY Jan~Dec VAH / VAL` | 该月 30m K 线的 TPO 70% 价值区，每行 100 个 tick，单行扩展（与 `engine.valueArea` 相同） | D1 月度探针：ETH 2025-11 VAL = 2707.00，参考值 2705.89，误差 0.04% |

## 2. 实现规格

### D10-1 预计算价位文件（Python + CI）

- 新脚本 `scripts/d10_build_levels.py`，复用 `scripts/c4_1_golden.py` 的 `load_range`、`weighted_stats`，以及与 `engine.valueArea` 相同的 TPO 70% 算法（D1 探针脚本里已有 Python 版本，抽成共用函数，不要再写第三份）。
- 对 BTCUSDT / ETHUSDT / SOLUSDT（USD-M）计算：
  - 今年**已结束**的每个季度，以及去年 Q1~Q4：`vwap`、`vah = vwap + σ`、`val = vwap − σ`
  - 去年 1~12 月：TPO 70% 的 `vah`、`val`
- 输出 `analysis/levels/{SYMBOL}.json`，每条记录：`{id, label, kind: "quarter"|"py-quarter"|"py-month", side: "VAH"|"VAL", price, periodStart, periodEnd, definition}`，标签写成 `Q2 VAH`、`PY Q4 VAL`、`PY Nov VAL` 这样。另有顶层 `generatedAt`、`cutoffUtc`。
- **缓存**：已经结束的周期结果不会再变。把每个周期的结果存到 data 分支 `levels/{SYMBOL}.json`，每天只计算缺少的周期。第一次运行需要下载约一年多的归档，之后每天几乎不下载。
- 接入 `pages.yml` 的 data job 和 Pages 打包步骤，PR 的 `analysis-smoke` 里也生成一份供浏览器测试使用。
- Python 测试：季度结果与 `c4_1_golden.py` 的 ETH 2026Q2 期望值一致（误差 ≤ 0.05%）；TPO 结果在 ETH 2025-11 上 VAL 与 2705.89 的误差 ≤ 0.3%；缓存命中时不触发下载。

### D10-2 页面画法（`web/analysis/*`）

- 页面加载 `analysis/levels/{SYMBOL}.json?v={generatedAt}`；文件不存在或加载失败时，不画这些线，表格里显示“缺失”，**不影响**其他内容。
- 候选价位排除上一季度（它就是图上已有的 PQ 灰色矩形，避免重复）。
- 选取规则：价格落在当前视图价格范围 ± `visiblePadPct` 以内；按与现价的距离由近到远，最多 6 条（`config/analysis-rules.json` 新增 `keyLevels.maxCount: 6`）。
- 画法：
  - 季度类：白色虚线 `rgba(236,239,244,.75)`，1px，横跨整张图
  - 去年月份类：青色实线 `#4fc3f7`，1px
  - 线的右端、价格轴左侧写标签；价格轴上白底黑字的价格标签，参与 D5 的标签避让（不能压住最新价标签）
  - 两条线价格相差小于 1 个 tick 时合并成一条，标签用 ` · ` 连接，例如 `Q2 VAL · PY Q4 VAH`
- 表格加入这些价位：类型（标签）、价格、距现价 %、计算周期（`Q / 1h VWAP±1σ` 或 `M / 30m TPO`）。没画在图上的标 `（图外）`。
- 图例加一项 `关键价位`（白色虚线）。

### D10-3 测试（`scripts/d1_smoke.cjs`、`scripts/d1_daily_png.cjs`）

- 用一个固定的 levels fixture：画出的线 ≤ 6 条，且都在视图价格范围 ± pad 以内；上一季度没有被重复画成线；相差小于 1 tick 的两条被合并成一个标签。
- 价位文件 404 时，页面正常加载，表格出现“缺失”，其他断言不变。
- 所有可见的价格轴标签距最新价标签 ≥ 18px（沿用 D5 断言）。
- 每日 PNG 的 manifest 每张图增加 `keyLevels`（画出的条数）。
- D2~D9 已有断言全部保留。
